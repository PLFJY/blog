这是一篇迟到文章，首先祝自己生日快乐吧，本来也没想好要写些啥，就随便记录一下

序

一转眼就 18 岁了，仿佛昨天还是 21 年的那个夏天，那万恶的 8 月 31 日，这几年里，时间过得好像很慢又好像很快。快，是快在不知不觉就结束了中考，也进入了高三；

慢，是慢在防沉迷没解顶着未成年这种人下人的身份，哪哪都走不通，本来想着拿我爸的身份顶一下就好了，结果麻烦事还在后面——人脸识别，看到一个四五十大叔凌晨玩个梦之女巫乱杀全场，那必然得弹的，然后……就废了；

快，是一眨眼就到了，仿佛还在昨天，真正到了生日那天反而没了 5 年前的那种欣喜，那个 5 年没上的账号是真的好穷，啥都没有；那种日日夜夜翘首以盼的感觉总算到来的那一刻，真的是令我充分认识到，人，是会变化的，当年想做的，尽可能去做吧，免得以后有时间能做了，没这个心情做了；

就在这难熬的日子里，我等来了我这几年里很重要的一位贵人，感谢羽涅给我提供的帮助，让我撑过了这难熬的时间，很抱歉我一直在这方面对你包有不少警惕，不过真的真的十分感谢你的帮助；

我与第五人格 BP / 直播辅助软件的孽缘

然后就是这段时间我折腾的各种软件工程了。先是被算法竞赛搞崩了心态，六年级和初一那几次 CSP-S 之后就没想过好好学习代码。

直到，2022 年，那是我第一次加入 ASG，我依然记得，当时是在 B 站刷到了 ASG 的账号看到正在直播，然后跟浊泉提出，想当解说，无奈，段位太低，理解不够；

然后我灵机一动，表示：我想来试试导播，我看当时 ASG 的录像都挺简陋的，于是表示，我会 OBS，可以折腾 BP 界面出来！实际就是，一开始浊泉见我年龄太小，然后在我的死缠烂打之下，他就先让我跟着落雪一块折腾直播画面，当时还是落雪在弄直播画面；那次是我第一次把民间赛的 BP 界面搬上 ASG，然后就会发现，OBS 真的是手忙脚乱的，手动选图片是真的累；

之后去 ZSL 当了一段时间外包，知道了皮塞东丶大佬开发的复旦第五人格协会弄的 python bp 界面软件，我就寻思……功能不够多，我要魔改一下；

然后就开始魔改 python 的代码，当时真的是磕磕绊绊，给头像改成了全身立绘，给我高兴的不得了；

然后就在想，能不能弄上比分显示？

那……我重新写一个吧，然后……开始了学习易语言，真的就是哪里亮了点哪里，哪里不会搜哪里，搓出了我的第一个废案：模仿当年 IVS 的 3D 场景切换，后来录了一大堆素材，反正废掉了，太麻烦了，不过那个时候，对局步骤引导的理念已经渐渐成型；

idv-bpsys-asg

过了一段时间，我的第一作诞生了——idv-bp-asg-e，易语言打造的 Bp 软件，现在还是 BP 软件，后来得升级了；当时就已经极其先进的有了：队伍管理（LOGO、选手、选手换位、换边）、角色 BP、BP 倒计时、比分系统、地图 BP、ban 位数量设定，并附带有 5 个前台界面：BP 主窗口、过场画面、游戏内比分*2、地图 BP；简直是先进到极致了；用了一段时间，大家都说好；

这段时间，罗澜加入了我们赛事组，并和浊泉一起两人一起做出了我们的后台管理，包括解说选班、赛事赛程、选手报名什么的，真的是当时我们是真的高级来的；

bp-sys-wpf

我对易语言的了解不深，而且易语言的透明图片显示一直是硬伤，很限制发挥。机缘巧合罗澜给我介绍了微软家的几个框架：UWP、WPF、WinFrom，我发现 WinForm 没法弄透明图片，于是，最终选择了 WPF，事实证明，这是极其正确的一个道路，因为 UWP 后来都被微软自己放弃了 :)，然后经过了一段时间的学习和研究，看了几期丑萌气质狗的视频，然后做出了我的第二作——bp-sys-wpf；

虽然功能还是一样，但是流畅性、交互性方面，完全吊打易语言版本，同时由于角色图片可以直接透明放上去，给了我更好的发挥空间，这时候，加入了分数统计界面的编辑功能，同时加上了角色待选择的时候亮起的白色边框、角色选择动画；简直是帅炸了，此外还弄上了自动更新下载（虽然是极其危险的代码就是了）和选手上下场的功能；

甚至当时已经极其先进的拥有了使用配置文件修改文字颜色和文字字体的能力，以及使用 JSON 导入队伍信息的能力；

v3 版本使用了伪 MVVM 做了重构，弄了全局禁选，但是给项目结构搞得一团糟，后台已经换上了现代化 UI，并且上了新版的更新器；

直到有一天，更新了新的全局禁选，完全读不懂以前的代码了，于是就只能复制粘贴了，我开始发现了问题的严重性，开始了重构；

重生：neo-bpsys-wpf

仔细学习了十月的寒流的 IOC 教程之后，我开始了重构，于是，我的三作就这么诞生了——neo-bpsys-wpf，这一代简直是神作来的，因为，它不但完成了，并且，创新性的引入了：可扩展的拼音角色选择器、选手数量动态添加、前台设计者模式、步骤引导、赛后数据、选手定妆照、BO3、BO5 赛制切换、角色待选择框的闪烁效果；尤其是设计者模式，简直是开天辟地级别的，当时的我自己觉得的设计思路简直觉得自己像天才，后面 AI 编程兴起之后觉得自己好蠢；

neo-v2

v2 我发现了有外国友人在使用，我们开始了国际化的相关功能开发，由 Zack 全权负责了各项翻译，这位也是我的一位贵人来的，非常感谢他在 neo-bpsys-wpf开发期间的全力帮助，帮我减轻了很多的负担；同时，我也在研发赛后数据的全自动识别和插件系统，最终，也是顺利上线了；

这中途不知道哪一次加了前台深度自定义并支持导出 .bpui 文件，也是笨拙的实现方式，后来这一切要被推翻了；

neo-v3

这次是革命性的更新，我整个给设计者模式整个废掉了，改成了新的 v3 设计器模式，前台窗口渲染一切交由 runtime 执行，现场根据配置文件构建前台界面，不再是预制菜，然后，可以交由用户自行开始设计和自由发挥，动画也是自己写，所有的属性也是自己改，比分系统也彻底的进行了重构，真正把自由对局和标准对局给区分开了，bpui 包的标准也有了事实性的更改，这次，也是我们终于有了彻底可以跨渲染器的标准，只要渲染器实现了这些功能，一律都可以渲染这些前台元素；有了 Codex 和 GLM 的帮助，我这一轮大重构相当的成功；这一次的更新，在 GPT 的建议下，最终取名为帷幕的回响。此外智慧 BP 也单独拆成了一个独立模块，感谢枫零提供给我的设计思路，利用坐标聚类而不是独立切片彻底实现了全过程，全自动的自动识别，给我高兴坏了！

微软账号被盗事件

详细过程不想再讲一遍了，有兴趣可以直接去看看 -> 记录一次微软账号被盗的经历 ；

真的是给我警钟长鸣吓坏了，重新对网络安全有了新的认知，至少是隐私和账号安全方面，直接对自己现有的混乱安全体系做了大重构；

但是……我的 Hypixel 账号呜呜呜——，永别了，微软我日你仙人，气死你大爷我了！

ContextMenuMgr

这又是一个全新写的故事，这次是我的微软盗号事件之后重装系统，发现安装软件老是要处理右键菜单太麻烦了，然后一气之下说，既然能管理，为什么不能连 Win11 的一起管理？为什么不能先拦下来再让用户审批？说干就干，经历了一段时间过后，我的纯 Vibe Coding 第一作就这么诞生了，自己做了视频做了宣发做了维护，感觉……很受社区好评，并且我极致的压缩后台占用，避免了各种社区声讨，总的来说……还是不错的吧！

个人主页和个人博客

在 Vibe Coding 兴盛之前，我给先用 Hexo 弄过一个个人博客，那叫一个烂的啊，啥也不是，全部都没配合好，后来我老老实实读文档，重新用 Redefine 主题弄了一个，现在就在用，弄得挺不错的，还自己用注入 css 和 js 改了不少东西，包括现在用来写东西的后台，Vibe 了一个出来写起文章来是真的舒服，个人网站也是 Vibe 出来的， 后面还会重新手搓的，现在只是没空，嗯；

UP 主之路

这一条差不多是废掉了，以前总妄想自己能成为跟 Fo 一样的大主播，现在看来……嗯，做自己喜欢的内容就好吧，不过这也挺神奇的，我自己学了剪辑，自己学了简单的修图，然后粉丝基础又让我的视频推流得到了一定的保障，至少我软件的宣传片会有人看；同时感谢高中社团里神部的各位大佬们，我在这里加强了之前自己修音的技能，这也补上了我一块很重要的地图；

这一段过来，感觉……仿佛昨天还是 21 年被防沉迷打的抬不起头的那个我，浑然不觉已经成年，这一段时间以来肝了很多，干了很多，也干出了很多。时间完全不够用，又其实有很多，一件又一件，一件连着一件，干也干不完，想学的东西也学不完。唉，看来……后面还有新的路要走了，摆脱了人下人的身份，终于是正常人了。感谢一路当中我遇到的陌生人们，你们都是我的贵人，感谢我的父母，一路以既不支持也不反对的方式默默的让我自由的发展。感谢我自己，愿意在不断的发掘自己喜欢的事物，就这样吧，后面路还很长，还得走呢；
